---

Bamboo scans your JavaScript and TypeScript for style props and function calls, and generates atomic CSS for the call
sites it finds. It runs as a CLI or a PostCSS plugin.

You author styles as plain objects. Tokens, recipes and variants are generated from your config as types, so the editor
autocompletes them and the compiler checks them.

## How is this different from Panda CSS?

Bamboo CSS is a fork of [Panda CSS](https://panda-css.com/) v1, so the styling API is identical and
[migrating](/docs/migration/panda) is mostly a rename. What changed is what reaches the browser and what it costs — see
[why we forked](/docs/overview/why-bamboo#why-we-forked-panda-css) and
[what changed](/docs/overview/faq#how-is-bamboo-css-different-from-panda-css).
